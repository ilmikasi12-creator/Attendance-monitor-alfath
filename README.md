# 🌙 Sistem Absensi Pesantren (Attendance Monitoring System)

Sistem informasi berbasis mobile (Flutter) untuk memantau absensi dan kedisiplinan santri di lingkungan pesantren secara *real-time*.

## 📌 Fitur Utama

### 📱 Hak Akses & Role User:
1. **Koordinator:** Dashboard ringkasan seluruh departemen, statistik harian/pekanan/bulanan/tahunan, pantauan santri prioritas, serta analisis tren absensi.
2. **Departemen Tarbiyah:** Absensi Qoilulah, Tidur Malam, Asrama, Hadiri Kamis, serta pencatatan kasus kedisiplinan santri.
3. **Departemen Diniyyah:** Absensi Diniyyah Pagi, Mutola'ah, dan Hafalan Kitab.
4. **Departemen Tahfiz:** Absensi Tahfiz Subuh, Tahfiz Siang, dan Manzil.

### ⚡ Fitur Sistem:
* Antarmuka **Material Design 3 (Dark Mode)** yang modern dan responsif.
* **Santri Prioritas:** Tracking santri dengan tingkat ketidakhadiran tinggi beserta status pembinaan (*Belum Dipanggil, Dipanggil, Dalam Pembinaan, Selesai*).
* **Ekspor Laporan:** Dukungan ekspor data ke format PDF dan Excel.
* **Bahasa:** 100% Bahasa Indonesia.

---

## 🛠️ Arsitektur & Teknologi
* **Framework:** Flutter (Dart)
* **UI Style:** Material Design 3 (Dark Theme)
* **Backend / Database:** Firebase Firestore / Supabase (Scalable Normalized Schema)
